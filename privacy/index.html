プライバシーポリシー

最終改定日: 2026年6月10日

音声・テキストは端末の外に出ません（Zero-Egress）

LuxVoice（以下「本アプリ」）は、あなたの声とテキストを最大限に尊重して設計されています。本アプリは、音声の認識および文章の整形をすべてあなたのデバイス上で行い、その内容を開発者や第三者のサーバーに送信しません。

1. 本アプリが収集しない情報

  • 音声データ: あなたが録音した音声はデバイス内で処理され、開発者は一切取得しません。
  • 認識結果・整形結果: 音声から変換・整形されたテキストはデバイス内に保存され、開発者のサーバーには送信されません。
  • 本アプリはアカウント登録を必要とせず、氏名・メールアドレス等の個人情報を収集しません。
  • 広告 SDK・解析 SDK・トラッキング SDK を使用しません。

2. デバイス内での処理（オンデバイス）

  • 音声認識: オンデバイスの音声認識エンジン（WhisperKit）を使用し、デバイス内で完結します。
  • 文章整形: 対応端末では Apple のオンデバイス AI（Foundation Models / Apple Intelligence）を使用し、デバイス内で整形します。非対応端末では、ルールベースの処理と辞書置換のみを使用します。
  • いずれの処理も、音声・テキストを外部に送信しません。

3. iCloud 同期（任意）

  • 本アプリは、ユーザー辞書とテンプレートのみを、Apple の iCloud（NSUbiquitousKeyValueStore）を通じてあなたの端末間で同期できます。
  • 同期されるのは辞書とテンプレートのみで、音声・認識結果・入力履歴は同期されません（端末内にのみ保存）。
  • iCloud 上のデータはあなたの Apple ID アカウント内に保存され、開発者はアクセスできません。
  • iCloud 同期は設定で無効化できます。

4. モデルのダウンロード

初回利用時に、音声認識モデル（WhisperKit）をダウンロードする場合があります。これはモデルファイルの取得のみであり、あなたの音声や入力内容を送信するものではありません。

5. アクセス許可

本アプリは以下の許可を、明示された目的のためにのみ使用します。

  • マイク: 音声を録音し、文字に変換するため。
  • 音声認識: 録音した音声をテキストに変換するため。
  • バックグラウンド音声: 録音中にアプリがバックグラウンドへ移っても音声を取りこぼさないため（録音セッションの継続のみに使用し、停止時に解放します）。

6. 第三者への提供

本アプリは、あなたのデータを第三者へ販売・提供しません。

7. データの保存と削除

  • 録音履歴・辞書・テンプレートは、あなたのデバイス内に保存されます。
  • アプリ内でこれらを削除できます。アプリを削除すると、デバイス内のデータも削除されます。

8. 子どものプライバシー

本アプリは、13歳未満の子どもから意図的に個人情報を収集しません。

9. 本ポリシーの変更

本ポリシーは必要に応じて更新されることがあります。重要な変更がある場合は、アプリまたは本ページで通知します。

10. お問い合わせ
